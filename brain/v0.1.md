# Brain Log — NeuralClaw

## v0.1.0 — 2026-04-26

### Decisiones de diseño

**DB global en ~/.config/**
- rationale: Simple, un solo lugar, compartido entre proyectos
- alternative: DB por proyecto (portabilidad, complejidad extra)
- status: ✅ decided

**Sync (no async)**
- rationale: Uso local single-agent, async es overhead innecesario
- alternative: aiosqlite para concurrent access (futuro si se necesita)
- status: ✅ decided

**Keyword search (no embeddings)**
- rationale: FTS5 de SQLite + LIKE basta para el uso esperado, funciona offline
- alternative: Ollama embeddings para búsqueda semántica (fase 4)
- status: ✅ decided

**Vault global**
- rationale: Una sola clave, más simple de gestionar
- alternative: Vault por proyecto (más隔离, más complejo)
- status: ✅ decided

**FreshApple auto-refresh híbrido**
- rationale: TTL 1h por defecto, configurable
- alternative: Solo manual / auto-total
- status: ✅ decided

**Output solo a stdout**
- rationale: Unix way, pipe-friendly, archivo opcional con --output
- alternative: Archivo + stdout por defecto
- status: ✅ decided

**CLI stand-alone (PyPI)**
- rationale: Independiente de cualquier tool, máxima portabilidad
- alternative: OpenClaw skill (post-MVP si tiene sentido)
- status: ✅ decided

## Schema SQL — Decisiones

### 8 tablas + FTS5 + triggers
1. `projects` — proyectos activos/archivados
2. `context_items` — items de contexto (key/value por proyecto)
3. `context_links` — relaciones entre items (supersedes, contradicts, etc.)
4. `errors` — log de errores por proyecto
5. `decisions` — log de decisiones con rationale
6. `usage_logs` — audit trail de operaciones
7. `model_profiles` — perfiles de comunicación por LLM (Train Room)
8. `fresh_apple` — snapshots de contexto activo
9. `vault_entries` — metadata de secrets (valores cifrados en vault.db)

**FTS5 virtual table** + **triggers** para mantener sync — preparado para fase 4 cuando se active full-text search.

## Vault — Decisiones

- Key en `~/.config/neuralclaw/vault.key` (no en vault/)
- vault.db en `~/.config/neuralclaw/vault/` (gitignored)
- Fernet encryption (cryptography)
- Nunca exponer valores reales a la IA — solo `{{VAR_NAME}}` por defecto
- `--include-vars` + adapter con `reveal_vars: true` para revelar

## Adapters — Decisiones

Cada adapter define:
- `context_format.prepend/append`
- `max_tokens`
- `supports_system / supports_functions`
- `reveal_vars`
- `preferences` (length, style, markdown)
- `constraints`

Adapters incluidos en MVP:
- `openclaw` — máximo 200k tokens, reveal_vars: true, style: direct
- `chatgpt` — 128k tokens, functions: true, reveal_vars: false
- `claude` — 200k tokens, functions: true, style: technical

## Errores y learnings

### Error: MATCH en FTS5 sin contexto
- Mensaje: `OperationalError: unable to use function MATCH in the requested context`
- Causa: SQLite FTS5 MATCH solo funciona contra la virtual table, no contra la tabla base
- Fix: Usar LIKE para keyword search en MVP (MATCH queda para fase 4 con FTS5 completo)
- Tags: sqlite, fts5, search

### Error: Typer script entry point
- Mensaje: `TypeError: 'module' object is not callable`
- Causa: El entry point `neuralclaw = "neuralclaw.cli:main"` apuntaba al módulo, no al objeto `app`
- Fix: `neuralclaw = "neuralclaw.cli.main:app"`
- Tags: typer, entry-point, packaging

### Error: appdirs no incluido en deps
- Mensaje: `ModuleNotFoundError: No module named 'appdirs'`
- Fix: Agregar `appdirs>=1.4.0` a dependencies en pyproject.toml
- Tags: dependencies, packaging
